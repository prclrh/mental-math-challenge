# 四则运算挑战 · 100 以内加减乘除练习

一个零依赖的单文件网页小游戏：限时刷四则运算题，实时判分，结束后给出成绩单和错题回顾。难度、题量、时长都能自己调，适合给孩子做口算练习。

**直接用浏览器打开 `math-game.html` 即可开始，不需要安装任何东西。**

## 功能

| 功能 | 说明 |
| --- | --- |
| 四则运算 | 加、减、乘、除随机出题，所有运算数、中间值与结果都在设定范围之内；除法保证整除 |
| 难度分级 | 入门（10 以内加减）、基础（20 以内 + 表内乘除）、标准（100 以内四则）、挑战（100 以内 + 两步混合运算） |
| 自定义难度 | 数字上限 10 / 20 / 50 / 100 可选，加、减、乘、除任选组合（至少一种），可开关两步混合运算 |
| 题量可调 | 20 / 50 / 100 / 200 题快捷选择，或自定义 5 – 500 题 |
| 时长可调 | 1 / 2 / 3 / 5 分钟快捷选择，或自定义 30 – 3600 秒 |
| 实时计时 | 顶部倒计时 + 进度条，最后 30 秒变红提醒，时间到自动结算 |
| 即时判分 | 提交后立刻显示对错，答错给出正确答案；答对停 0.62 秒、答错停 1.05 秒后自动跳下一题 |
| 实时统计 | 已答题、正确、错误、正确率四项实时刷新 |
| 主动交卷 | 时间结束前可随时交卷，未作答题目记为漏答 |
| 成绩总结 | 正确率、用时、答对数、答错+漏答数，以及可滚动的错题列表（原题 / 你的答案 / 正确答案） |
| 键盘操作 | 回车提交；反馈期间再按回车可立即跳到下一题 |
| 移动端适配 | 响应式布局，输入框唤起数字键盘，适配手机与平板浏览器 |
| 记忆设置 | 上次的难度、题量、时长会存在浏览器本地，下次打开直接沿用 |

## 设置的呈现方式

当前设置会在四个位置同步显示，改完不用记：

1. 设置面板底部的摘要条：`标准 · 100 以内 · 100 题 · 03:00 · 加减乘除`
2. 开始按钮文案：`开始挑战 · 100 题 / 03:00`
3. 游戏中顶栏副标题：`标准 · 100 题 · 03:00`
4. 结算页的「本局设置」回显

## 使用

直接双击 `math-game.html`，或用任意浏览器打开：

```bash
# macOS
open math-game.html

# Windows
start math-game.html
```

手机上可以用浏览器的「添加到主屏幕」，获得接近 App 的全屏体验。

## 测试

`tests/game-smoke.js` 用 jsdom 在无浏览器环境下跑完整个交互流程，覆盖 55 项断言：设置项改动的即时反馈与校验、答题判分、回车跳过、提前交卷、结算回显、时间到自动结算、重新开局等。倒计时部分用虚拟时钟加速 1000 倍验证。

```bash
# 安装测试依赖（仅测试需要，游戏本身零依赖）
npm install jsdom

# 运行
NODE_PATH=./node_modules node tests/game-smoke.js
```

出题逻辑额外做过随机采样校验：10 种配置组合 + 20 万道混合运算题，越界和不整除违规均为 0。

## 实现要点

- **计时精准**：以 `endTime = Date.now() + 时长` 为基准，每 100ms 轮询计算剩余时间，不受 `setInterval` 漂移和标签页后台节流影响。
- **状态机**：`idle → playing → feedback → ended` 四态驱动，避免重复提交和重复计数。
- **出题约束**：每类运算按上限反推取值范围（如乘法按 `上限 / 因数` 反推另一个因数），保证不越界；除法由除数与商相乘得到被除数，天然整除。
- **题型配比**：四则运算均匀轮转，开启混合运算时每 4 题插入 1 道混合题（占 25%）；同一局内尽量避免重复出题。
- **零依赖**：不引入任何框架或外部资源，单文件可离线运行。

## 已知限制

入门难度（10 以内加减）全部不重复的题目约 65 种，因此选择 100 题以上时，同一局内会出现重复题目——这是「10 以内」这一约束本身导致的。需要更高重复度容忍以外的变化，可选用基础及以上难度。
